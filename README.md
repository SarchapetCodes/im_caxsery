# Ծախսերի հաշվիչ

Flutter հավելված՝ ամենօրյա ծախսերը գրանցելու, տեսակավորելու և գումարը հաշվելու համար։

## Կառուցվածք

- `models/` — Expense մոդելը և ExpenseCategory enum-ը։
- `data/` — սկզբնական տվյալների ցուցակը։
- `screens/` — գլխավոր էջը և գումարը խմբագրելու էջը։
- `widgets/` — առանձին ծախսի տողը և category-ների ֆիլտրը։

## Հարցերի պատասխաններ

### 1. Որտե՞ղ եք պահում ծախսերի ցուցակը և ինչու այնտեղ

Ծախսերի ցուցակը պահում եմ `HomeScreen`-ի `_HomeScreenState`-ի մեջ՝ `_expenses` փոփոխականում։ Ցուցակը կապված է գլխավոր էկրանի վիճակի հետ․ երբ ծախս եմ ավելացնում, ջնջում կամ խմբագրում, կանչում եմ `setState()`, և Flutter-ը թարմացնում է էկրանը։ Այդ պատճառով այն պահում եմ հենց այն էջի State-ում, որտեղ ցուցակը կառավարվում է։

### 2. Ինչպե՞ս եք հաշվում ընդհանուր գումարը, և ինչու այն չեք պահում առանձին փոփոխականում

Ընդհանուր գումարը հաշվում եմ `_visibleTotal` getter-ով՝ ցուցակի `fold()` մեթոդի միջոցով։ Այն գումարում է տվյալ պահին ցուցադրվող ծախսերի գումարները։ Առանձին փոփոխական չեմ պահում, որպեսզի ցուցակի փոփոխությունից հետո ընդհանուր գումարը չմնա հին արժեքով և տվյալները չկրկնվեն։ Ֆիլտր ընտրելիս getter-ը հաշվում է միայն ընտրված category-ի ծախսերը։

### 3. Ինչո՞ւ է Dismissible-ի key-ը expense.id, ոչ թե index

Օգտագործում եմ `ValueKey(expense.id)`, որովհետև id-ն եզակի և տվյալ ծախսին կապված արժեք է։ Ցուցակից տարր ջնջելիս index-ները փոխվում են, և Flutter-ը կարող է սխալ նույնականացնել ցուցակի տարրերը։ Իսկ id-ն չի փոխվում, նույնիսկ եթե ծախսի դիրքը ցուցակում փոխվի։
